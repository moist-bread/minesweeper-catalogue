## **DESCRIPTION**

The `Minesweeper Catalogue` is a showcase of the programming languages i've learnt over the years in the form of my favorite leisurely game.

The plan is for this repository to keep growing and for each one of the games to have it's own visual identity so that it can be told apart for the others.
